## 一、终端与系统基础

| 命令 | 作用 |
| --- | --- |
| `hostname [新名字]` | 临时修改机器名（重启失效） |
| `su` | 切换到 root（真管理员）权限，`exit` 退出 |
| `clear` | 清屏（快捷键 `Ctrl + L`） |
| `Ctrl + C` | 退出当前错误的命令或正在运行的程序，回到提示符 |
| `Tab` | 自动补齐（单击补齐，双击列出所有相似开头的文件 / 命令） |
| 上下方向键 | 快速调取历史命令 |
| `\` | 换行符，用于将长命令换行输入 |

### 绝对路径与相对路径

- **绝对路径**：以 `/` 开头（如 `/etc`）。
- **相对路径**：不以 `/` 开头，相对于当前所在目录（如 `Desktop`）。

## 二、目录与文件操作

| 命令 | 作用 |
| --- | --- |
| `pwd` | 显示当前所在目录的绝对路径 |
| `cd` | 切换目录 |
| `cd /` | 切换到根目录 |
| `cd ~` | 切换到当前用户的家目录 |
| `cd ..` | 切换到上一级目录 |
| `ls` | 列出目录内容 |
| `ls -l` | 以长格式显示（权限、大小、时间等） |
| `ls -h` | 以人类可读方式显示文件大小（K、M、G） |
| `ls -a` | 显示隐藏文件（以 `.` 开头的文件） |
| `ls -t` | 按时间排序（常组合为 `ls -lt` / `ls -alt`） |
| `tree` | 以树形结构显示目录（需 `apt install tree`） |
| `mkdir` | 创建目录 |
| `mkdir -p dir1/dir2` | 递归创建多级目录 |
| `touch` | 新建空白文件 |
| `cp` | 复制文件或目录 |
| `cp -r` | 递归复制目录 |
| `mv` | 移动文件 / 目录，或重命名 |
| `mv 原文件名 新文件名` | 重命名 |
| `mv 文件名 目录路径` | 移动 |
| `rm` | 删除文件或目录（物理删除，无法复原） |
| `rm -rf 目录/文件` | 强制递归删除（极其常用，慎用） |
| `rmdir` | 只能删除空目录（不实用） |

## 三、文件查看与编辑

### 1. 查看文件内容

| 命令 | 作用 |
| --- | --- |
| `cat` | 连续输出文件所有内容 |
| `cat -n` | 带行号（含空行） |
| `cat -b` | 带行号（去空行） |
| `tac` | 倒序查看文件内容 |
| `head -n [行数]` | 查看文件头几行（默认 10 行） |
| `tail -n [行数]` | 查看文件末尾几行 |
| `tail -f 文件名` | 实时跟踪文件更新（常用于看日志） |
| `more` | 分页查看文件 |

`more` 常用按键：

- `空格`：下一页
- `b`：上一页
- `回车`：下一行
- `q`：退出

### 2. vi / vim 文本编辑器

**模式切换**：按 `i` 进入编辑模式；按 `Esc` 退出编辑模式。

| 操作 | 说明 |
| --- | --- |
| `/关键字` + 回车 | 非编辑模式下搜索，按 `n` 查找下一个 |
| `:set nu` | 命令行模式显示行号 |
| `H` / `J` / `K` / `L` | 非编辑模式下代替方向键：左 / 下 / 上 / 右 |
| `dd` / `2dd` / `ndd` | 删除 1 行 / 2 行 / n 行 |

**保存与退出**（输入 `:` 进入底层命令模式）：

| 命令 | 作用 |
| --- | --- |
| `:wq` | 保存并退出 |
| `:q` | 未修改内容时退出 |
| `:q!` | 修改了但不保存，强制退出 |

> **异常锁定**：异常退出会产生 `.swp` 隐藏交换文件，可按提示删除或使用 `vim -r` 恢复。

## 四、查找与搜索

| 命令 | 作用 |
| --- | --- |
| `find / -name "*.log"` | 从根目录按文件名查找所有 `.log` 文件 |
| `find / -size 1G` | 按文件大小查找 |
| `grep "error" 文件名` | 在文件内容中过滤包含 `error` 的行 |

### 管道符 `|`

**作用**：把前一个命令的**标准输出**（stdout）直接交给后一个命令的**标准输入**（stdin），中间不产生临时文件。

```
命令A 的屏幕输出  ──|──▶  命令B 的数据来源
```

**三个特点**

1. **不落盘**：数据只在内存中流动，不写成临时文件，速度快。
2. **可串联**：一条命令链可以有多个 `|`，每个命令只负责一件事。
3. **滤网思维**：前一个命令产生"原料"，后一个命令负责筛选、统计、排版。

**常见"过滤器"命令**

| 命令 | 在管道中的用途 |
| --- | --- |
| `grep 关键字` | 只保留匹配的行 |
| `grep -v 关键字` | 排除匹配的行 |
| `more` / `less` | 分页显示 |
| `head -n N` / `tail -n N` | 只看前 / 后 N 行 |
| `wc -l` | 统计行数 |
| `sort` | 按字典序排序（`-n` 按数字，`-r` 倒序） |
| `uniq -c` | 去重并统计出现次数（需先 `sort`） |
| `cut -d: -f1` | 按分隔符截取某一列 |
| `awk '{print $1}'` | 按空格取某一列 |
| `tee 文件名` | 一边显示到屏幕，一边写入文件 |
| `xargs` | 把上游输出变成下游命令的参数 |

**常用示例**

```bash
find / -size 1G | more                          # 查找结果分页显示
tail -f error.log | grep "error"                # 实时监控日志，只显示含 error 的行
ps -ef | grep nginx                             # 过滤出 nginx 相关进程
ps -ef | grep nginx | grep -v grep              # 再排除掉 grep 自己这一行
cat access.log | awk '{print $1}' | sort | uniq -c | sort -rn | head
                                                # 统计访问日志中出现次数最多的前 10 个 IP
du -sh * | sort -h | tail -5                    # 当前目录占空间最大的 5 个文件/目录
tar -xf pkg.tar -O file1 | grep "name"         # 不解压到磁盘，直接查包内文件内容
```

**注意事项**

- 管道只传**标准输出**（fd 1），**标准错误**（fd 2）默认仍打印在屏幕上；要让错误信息也进入管道，需先重定向 `2>&1`：

```bash
command 2>&1 | grep "error"
```

- 管道后面的命令**不能**是 `cd`、`alias` 这类只影响当前 shell 状态的命令，因为它们会运行在子 shell 中。
- `$?` 拿到的是管道中**最后一条命令**的退出码，不是整条链的（可用 `set -o pipefail` 改变）。
- 别把 `|` 和 `||` 混淆：`|` 是管道（传数据），`||` 是逻辑或（前一条失败才执行后一条）。

## 五、权限管理（chmod）

**权限代号**：`r`（读，4）、`w`（写，2）、`x`（执行，1）

**角色代号**：`u`（所有者）、`g`（所属组）、`o`（其他人）、`a`（所有人）

### UGO 法（增减权限）

```bash
chmod g+w file      # 给所属组加写权限
chmod o-r file      # 去掉其他人读权限
chmod a+rwx file    # 给所有人授权读写执行
```

### 八进制法（直接赋值）

```bash
chmod 777 file      # 所有人最高权限 rwxrwxrwx
chmod 644 file      # 所有者 rw-，组 r--，其他人 r--
chmod -R 777 目录名  # -R 大写，递归处理目录下所有文件
```

| 八进制 | 权限 | 说明 |
| --- | --- | --- |
| 7 | `rwx` | 读 + 写 + 执行 |
| 6 | `rw-` | 读 + 写 |
| 5 | `r-x` | 读 + 执行 |
| 4 | `r--` | 只读 |

## 六、压缩与打包

### 1. tar 命令

**命令结构**：

```bash
tar [主操作参数] [压缩参数] [辅助参数] 归档文件名 目标文件/目录
```

**主操作参数（三选一，不能同时使用）**：

| 参数 | 全称 | 作用 |
| --- | --- | --- |
| `-c` | create | 创建归档包（打包） |
| `-x` | extract | 从归档包中解压 / 解包 |
| `-t` | list | 列出归档包内容，不解压 |
| `-r` | append | 向已有 tar 包**末尾追加**文件（不能用于压缩包） |
| `-u` | update | 只追加比包内更新的文件（不能用于压缩包） |
| `-A` | concatenate | 合并两个 tar 包 |
| `-d` | difference | 比较归档包与当前文件系统的差异 |

**压缩参数（三选一，按压缩算法区分）**：

| 参数 | 对应格式 | 说明 |
| --- | --- | --- |
| `-z` | `.tar.gz` / `.tgz` | 使用 gzip 压缩，速度最快、最常见 |
| `-j` | `.tar.bz2` | 使用 bzip2 压缩，体积更小但更慢 |
| `-J` | `.tar.xz` | 使用 xz 压缩，压缩率最高、最慢 |
| `-a` | 自动 | 按归档文件后缀自动选择压缩方式 |

> 注意：**只有打包（`-c`）时才需要加压缩参数**。解压（`-x`）和查看（`-t`）时 tar 能自动识别压缩格式，加 `-z` 只是保险，不加也能解压。

**常用辅助参数**：

| 参数 | 作用 |
| --- | --- |
| `-v` | verbose，显示处理过程（列出被打包 / 解压的每个文件名） |
| `-f` | file，指定归档文件名，**必须紧挨着文件名且放在其他参数之后** |
| `-C` | 切换目录：打包时先 `cd` 到该目录再操作；解压时把文件解到该目录 |
| `-p` | 保留原文件的权限与所有者信息（解压时常用） |
| `-P` | 保留绝对路径（默认会去掉开头的 `/`） |
| `-h` / `-L` | 跟随符号链接，打包链接指向的真实文件 |
| `-k` | 解压时不覆盖已存在的文件 |
| `-m` | 解压时不恢复文件的修改时间，改用当前时间 |
| `-O` | 把内容输出到标准输出（配合管道使用） |
| `-T` | 从指定文本文件中读取要打包的文件名列表 |
| `-X` | 从指定文件中读取要排除的文件名列表 |
| `--exclude=模式` | 打包时排除匹配的文件 / 目录（支持通配符） |

**为什么 `-f` 必须放最后**

`-f` 后面紧跟的参数会被当作归档文件名，如果写成 `tar -f yasuo.tar.gz -zcv file1`，tar 会把 `-zcv` 认成文件名。除非把参数合并写在一起（`-zcvf yasuo.tar.gz`），否则 `-f` 一定放最后。

```bash
tar -cvf daba0.tar file1 file2                    # 打包（不压缩）
tar -zcvf yasuo.tar.gz file1 dir1                 # 压缩（打包 + gzip）
tar -jcvf yasuo.tar.bz2 dir1                      # 打包 + bzip2
tar -tvf yasuo.tar.gz                             # 查看包内容
tar -xvf yasuo.tar.gz                             # 解压（自动识别 gzip）
tar -zxvf yasuo.tar.gz -C /opt/backup             # 解压到指定目录
tar -xf yasuo.tar.gz dir1/file1.txt               # 只解压包中某个文件
tar -zcvf backup.tar.gz --exclude="*.log" /var    # 打包时排除 .log 文件
tar -rvf daba0.tar newfile.txt                    # 追加文件到未压缩的 tar 包
tar -xf daba0.tar -O file1 | grep "name"          # 不落盘，直接输出并过滤
```

**参数记忆口诀**

- `c` 创建、`x` 解压、`t` 查看 → 决定想干什么
- `z` / `j` / `J` → 决定压缩算法
- `v` 看得见过程，`f` 指定文件（放最后），`C` 指定目录
- 一般组合：`-cvf`（打包）、`-zcvf`（压缩）、`-tvf`（查看）、`-xvf`（解压）

## 七、网络与系统管理

### 1. 网络查看

| 命令 | 作用 |
| --- | --- |
| `ifconfig` | 查看网卡 IP 地址信息（如 `eth0`） |
| `ping -c [次数] 域名/IP` | 测试网络连通性（`-c` 指定发送包数量） |

### 2. 进程与资源

| 命令 | 作用 |
| --- | --- |
| `top` | 动态查看 CPU、内存使用情况及进程资源占用（按 `q` 退出） |
| `free` | 查看内存占用量 |
| `du -h` | 查看当前目录 / 文件占用的磁盘空间 |
| `df -h` | 查看整个磁盘分区的使用情况 |
| `ps -ef` | 查看系统所有运行的进程（重点关注 PID 进程号） |
| `kill -9 [PID]` | 强制终止指定进程号的进程 |

### 3. 软件包管理（Ubuntu / Debian 体系）

| 命令 | 作用 |
| --- | --- |
| `apt update` | 更新软件源列表（类似应用商店刷新） |
| `apt install [软件名]` | 安装软件包 |
| `apt remove [软件名]` | 卸载软件包 |

### 4. 用户与时间

| 命令 | 作用 |
| --- | --- |
| `id` | 查看当前账号的 UID 和 GID |
| `passwd` | 修改当前用户密码（输入时不显示字符） |
| `date` | 查看系统日期和时间 |

### 5. 关机与重启

| 命令 | 作用 |
| --- | --- |
| `reboot` | 重启系统 |
| `shutdown -h now` | 立即关机 |
| `poweroff` | 关机 |
