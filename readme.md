# BWF-homework

## 📖 项目简介
本项目是 **BWF (Baidu Web Frontend / 百度Web前端)** 课程的学习作业汇总仓库。主要记录了在 MYSQL 数据库、WEB 前端开发以及软件测试理论方面的学习成果与实战练习。

## 📂 目录结构
本仓库包含以下三个主要模块：

- **📁 MYSQL**: 
  - 包含数据库相关的练习代码、SQL 脚本以及课程设计作业。
  - 涉及内容：增删改查(CRUD)、多表查询、存储过程等。

- **📁 WEB开发**: 
  - 包含前端开发的实战案例。
  - 涉及技术栈：HTML5, CSS3, JavaScript, 以及相关的前端框架练习。

- **📁 软件测试概论汇总**: 
  - 包含软件测试理论的学习笔记、测试用例设计文档及相关实验报告。
  - 涉及内容：黑盒/白盒测试、单元测试、集成测试等理论实践。
