# Python 面向对象基础笔记

## 一句话回忆

> 类是造车的图纸，对象是按图纸造出来的车；属性是车的颜色和型号，方法是车能跑、能鸣笛。

> 换成人话：**类=图纸（抽象模板），对象=车（具体实例），属性=车的特征，方法=车的行为。**
## 一、Python 不是只有面向过程

很多人（包括我）一开始以为 Python 是纯面向过程的语言，其实不是。

- **Python 同时支持面向过程和面向对象**，你可以像 C 那样写函数式代码，也可以像 Java 那样写类。
- Python 里"一切皆对象"——连 `int`、`str`、`list` 这些内置类型本质上都是类的实例。
- 面向过程：把程序拆成一个个**函数**，数据在函数间传来传去。
- 面向对象：把**数据和操作数据的函数**打包在一起，叫"类"。

## 二、类与对象

- **类（class）**：模板/蓝图，描述一类事物共同的属性和行为。
- **对象（object / instance）**：根据模板造出来的具体实例。

```python
class Person:                 # 定义类
    pass

p1 = Person()                 # 创建对象（实例化）
p2 = Person()                 # p1、p2 是两个不同的对象
```

## 三、类里面有什么：属性 + 方法

一个类说白了就两样东西：**属性**和**方法**。

> 拿"人"来打比方：
> - **属性** = 这个人的**特征**：姓名、年龄、性别、身高……（是数据，是名词）
> - **方法** = 这个人的**行为**：吃饭、睡觉、说话、跑步……（是动作，是动词）

```python
class Person:
    # 属性：描述"是什么样"（名词）
    def __init__(self, name, age):
        self.name = name        # 姓名
        self.age = age          # 年龄

    # 方法：描述"能做什么"（动词）
    def eat(self):              # 吃饭
        print(f"{self.name}在吃饭")
    def sleep(self):            # 睡觉
        print(f"{self.name}在睡觉")
```

**记住一句话：属性是名词（数据），方法是动词（行为）。** 定义类就是把"一类事物的特征和动作"打包在一起。

## 四、属性：类属性 vs 实例属性

| Python | Java | 一句话记忆 |
|--------|------|-----------|
| 类属性 | `static` 字段 | 属于类，所有对象共享一份 |
| 实例属性 | 普通字段 | 属于对象，每个对象各一份 |

```python
class Person:
    nationality = "中国"          # 类属性：写在方法外面，所有对象共享

    def __init__(self, name):
        self.name = name          # 实例属性：写在 __init__ 里，每个对象各一份
```

- **类属性**可以通过类名访问：`Person.nationality`
- **实例属性**只能通过对象访问：`p1.name`
- 对象修改类属性会变成"该对象自己的实例属性"，不会影响其他对象（这是 Python 的坑点）

## 四、方法：实例方法 vs 类方法 vs 静态方法

| Python | Java | 一句话记忆 |
|--------|------|-----------|
| 实例方法 + `self` | 普通方法 + `this` | 依赖具体对象 |
| 类方法 `@classmethod` + `cls` | `static` 方法 | 不依赖具体对象，但能访问类属性 |
| 静态方法 `@staticmethod` | `static` 方法（无参） | 既不依赖对象也不依赖类，纯工具函数，与类或者对象无关的方法 |

```python
class Person:
    nationality = "中国"

    # 实例方法：第一个参数 self 代表当前对象
    def say(self):
        print(f"我是{self.name}")

    # 类方法：用 @classmethod 装饰，第一个参数 cls 代表类本身
    @classmethod
    def identify(cls):
        print(f"我是{cls.nationality}人")

    # 静态方法：用 @staticmethod 装饰，没有 self/cls
    @staticmethod
    def hello():
        print("你好")
```

**判断技巧**：看方法第一个参数
- 是 `self` → 实例方法
- 是 `cls` → 类方法
- 没有 → 静态方法

### 静态方法的实际用途：工具函数

静态方法就是放在类里的**独立工具函数**，和类、对象都没关系，只是"借住"在类里方便管理。典型场景：正则校验、数据库连接、格式转换等。

```python
import re
import pymysql

class Utils:
    # 静态方法：校验手机号（和类、对象都无关，纯工具）
    @staticmethod
    def is_valid_phone(phone):
        return bool(re.match(r'^1[3-9]\d{9}$', phone))

    # 静态方法：连接数据库（不需要 self/cls）
    @staticmethod
    def get_db_conn():
        return pymysql.connect(host='127.0.0.1', user='root', password='root', database='bwf')

# 用类名直接调用，不需要创建对象
print(Utils.is_valid_phone("13812345678"))   # True
print(Utils.is_valid_phone("12345"))          # False

conn = Utils.get_db_conn()
print("数据库连接成功")
conn.close()
```

> **什么时候用静态方法？** 方法里既不需要 `self`（对象数据），也不需要 `cls`（类数据），只是个独立功能，就用 `@staticmethod`。它和写在类外面的普通函数一样，只是放在类里更整洁。

## 五、`__init__` 与 `self`

| Python | Java | 一句话记忆 |
|--------|------|-----------|
| `__init__(self, ...)` | 构造器 | 创建对象时自动执行 |
| `self` | `this` | 当前对象 |

```python
class Person:
    def __init__(self, name, age):   # 初始化方法，创建对象时自动调用
        self.name = name              # 把传入的参数存到对象身上
        self.age = age

p1 = Person("张三", 18)               # 自动调用 __init__，不用手动写方法名
# 等价于 Java: Person p1 = new Person("张三", 18);
```

- `self` 就是"当前这个对象"，相当于 Java 的 `this`
- `__init__` 不是必须的，没有它就用默认的空初始化

## 六、创建对象与调用方法

```python
p1 = Person("张三", 18)     # 实例化，自动调用 __init__
p1.say()                    # 调用实例方法
p1.identify()               # 对象也能调用类方法（cls 自动指向 Person 类）
Person.identify()           # 类名直接调用类方法
Person.hello()              # 类名调用静态方法
```

## 七、封装（私有属性）

Python 没有真正的私有，靠**命名约定**：

```python
class Person:
    def __init__(self, name):
        self.__name = name       # 双下划线开头：私有属性（外部不能直接访问）

    def get_name(self):
        return self.__name       # 提供公开的访问方法

p1 = Person("张三")
print(p1.get_name())             # 张三
# print(p1.__name)               # 报错，访问不到
```

- `__xxx`：私有，外部不能直接访问
- `_xxx`：约定俗成的"受保护"，外部能访问但不建议
- 本质上 Python 是把 `__name` 改名为 `_Person__name`，所以外部访问不到原名

## 八、继承

```python
class Animal:                     # 父类
    def eat(self):
        print("吃东西")

class Dog(Animal):                # 子类继承父类
    def bark(self):
        print("汪汪汪")

d = Dog()
d.eat()                           # 继承来的方法
d.bark()                          # 自己的方法
```

- `class 子类(父类):` 表示继承
- Python 支持**多继承**：`class C(A, B):`
- 方法重写：子类定义和父类同名的方法，会覆盖父类的
- `super()` 调用父类的方法

### 重载 vs 重写

很多人会把这两个搞混，它们完全不是一回事：

| | 重载（Overload） | 重写（Override） |
|---|---|---|
| **发生位置** | 同一个类里 | 子类对父类 |
| **方法名** | 相同 | 相同 |
| **参数** | 不同（个数/类型） | 必须相同 |
| **Python 支持** | ❌ 不支持 | ✅ 支持 |
| **Java 支持** | ✅ 支持 | ✅ 支持 |

**重写**（Python 支持）：子类把父类的方法重新实现一遍，覆盖掉父类的。

```python
class Animal:
    def speak(self):
        print("动物叫")

class Dog(Animal):
    def speak(self):              # 重写：方法名和参数和父类一样
        print("汪汪")              # 但实现不同
```

**重载**（Python 不支持）：同一个类里多个同名方法，靠参数区分。Java 可以，Python 里后定义的会覆盖前面的。

```java
// Java 可以这样，两个同名方法靠参数区分
class Person {
    void eat() { ... }
    void eat(String food) { ... }
}
```

```python
# Python 这样写只有最后一个生效，前面的被覆盖
class Person:
    def eat(self):               # 被覆盖，没用
        print("吃饭")
    def eat(self, food):         # 只有这个有效
        print(f"吃{food}")
```

**Python 实现"重载效果"**：用默认参数或可变参数。

```python
class Person:
    def eat(self, food="米饭"):   # 默认参数，不传也能用
        print(f"吃{food}")

p = Person()
p.eat()              # 吃米饭
p.eat("面条")        # 吃面条
```

> **一句话记忆**：重写是"子类改父类"（Python 支持），重载是"同类多个同名方法靠参数区分"（Python 不支持，用默认参数代替）。

## 九、多态

Python 的多态是"鸭子类型"——不关心对象是什么类，只关心它有没有对应的方法。

```python
def make_sound(animal):
    animal.speak()                # 只要传进来的对象有 speak 方法就能用

class Dog:
    def speak(self): print("汪汪")
class Cat:
    def speak(self): print("喵喵")

make_sound(Dog())   # 汪汪
make_sound(Cat())   # 喵喵
```

### ⚠️ 易混点：类方法 ≠ 多态

很多人会把"类方法（共用）"和"多态"搞混，其实它们是两回事：

| 概念 | 是什么 | 怎么实现 | 关键词 |
|------|--------|---------|--------|
| **类方法（共用）** | 属于类，所有对象共享同一份逻辑 | `@classmethod` 装饰 | 共用、一份 |
| **多态** | 同名方法，不同对象行为不同 | 继承 + 方法重写 | 同名、不同行为 |

```python
class Animal:
    # 类方法：共用，所有动物都一样
    @classmethod
    def kingdom(cls):
        print("动物界")

    # 实例方法：留给子类重写，实现多态
    def speak(self):
        pass

class Dog(Animal):
    def speak(self): print("汪汪")

class Cat(Animal):
    def speak(self): print("喵喵")

# 共用：不管 Dog 还是 Cat，结果都一样
Dog.kingdom()    # 动物界
Cat.kingdom()    # 动物界

# 多态：同样叫 speak()，不同对象行为不同
Dog().speak()    # 汪汪
Cat().speak()    # 喵喵
```

> **一句话记忆**：类方法是"大家都一样"（共用），多态是"同名不同样"（重写）。装饰器 `@classmethod` 只是标记方法类型，和多态没有关系。

## 十、常用魔术方法（双下划线方法）

| 方法 | 作用 | 对应 Java |
|------|------|----------|
| `__init__` | 初始化对象 | 构造器 |
| `__str__` | `print(obj)` 时调用 | `toString()` |
| `__len__` | `len(obj)` 时调用 | — |
| `__eq__` | `==` 比较时调用 | `equals()` |

```python
class Person:
    def __init__(self, name):
        self.name = name
    def __str__(self):            # 定义 print 时的输出
        return f"Person({self.name})"

print(Person("张三"))             # Person(张三)
```

## 总结

- Python 不是纯面向过程，**同时支持面向过程和面向对象**
- 类是模板，对象是实例
- 类属性/类方法属于类，实例属性/实例方法属于对象
- `self` = 当前对象，`cls` = 当前类
- `__init__` = 构造器，创建对象时自动调用
- 用双下划线 `__` 表示私有
- 支持继承、多继承、方法重写、多态
