# ISO 25010 质量模型实物测试用例集

## 1. 纸杯

> **核心关注点**：盛装液体的安全性、一次性使用的物理稳定性

- **功能适合性**
    - 能否正常盛装冷/热液体而不泄漏？
    - 容量是否符合标称（如 200ml）？
- **性能效率**
    - **隔热性**：装热水时，杯壁温度是否烫手？
    - **硬度**：装满水捏杯身时，是否容易变形导致水洒出？
- **兼容性**
    - 尺寸是否适配常见的汽车杯架、饮水机接水口？
- **易用性**
    - 杯口边缘是否圆润不割嘴？
    - 拿取是否防滑？
- **可靠性**
    - 长时间（如 2 小时）盛装液体，杯底是否软化渗漏？
    - 堆叠存放时是否稳固？
- **安全性**
    - 材质是否有毒（荧光剂检测）？
    - 遇高温是否释放有害物质？
- **可维护性**
    - （针对一次性用品）废弃后是否易于压缩、回收处理？
- **可移植性**
    - 重量是否轻便？空杯是否易于堆叠携带？

## 2. 笔

> **核心关注点**：书写的流畅度、寿命与便携

- **功能适合性**
    - 能否正常书写出墨？
    - 笔帽/按动开关功能是否正常？
- **性能效率**
    - **书写长度**：一支笔芯能写多少米/多少字？
    - **速干性**：写完后墨水多久干透（防蹭花）？
- **兼容性**
    - 笔芯规格是否通用（能否替换其他品牌笔芯）？
    - 是否适配特定的笔座或笔记本夹层？
- **易用性**
    - 握持手感是否舒适（笔杆粗细、软硬度）？
    - 书写是否需要很大力气？
- **可靠性**
    - 跌落地面后是否还能正常书写？
    - 放置很久不用（如一个月），起笔是否顺畅（不易断墨）？
- **安全性**
    - 笔帽是否有透气孔（防止儿童吞咽窒息）？
    - 墨水是否无毒？
- **可维护性**
    - 是否易于更换笔芯或加墨水？
    - 笔身脏了是否容易擦拭清洁？
- **可移植性**
    - 是否防漏墨（放在口袋里是否会弄脏衣服）？
    - 是否有笔夹方便携带？

## 3. 电梯

> **核心关注点**：安全性、调度逻辑与运载能力

- **功能适合性**
    - 能否准确到达指定楼层？
    - 开关门功能是否正常？
- **性能效率**
    - **速度**：楼层间运行时间是否达标？
    - **响应时间**：按下按钮后，电梯到达的平均等待时间。
- **兼容性**
    - 是否支持多种支付/控制方式（刷卡、二维码、人脸识别）？
    - 是否与火灾报警系统联动（火警时自动迫降首层）？
- **易用性**
    - 按钮高度是否适合轮椅使用者/儿童？
    - 显示屏/语音播报是否清晰指示当前楼层和方向？
- **可靠性**
    - 频繁开关门是否故障？
    - 满载运行是否稳定？
    - 平均无故障时间 (MTBF) 是多少？
- **安全性**
    - **防夹功能**：门关闭时遇到障碍物是否自动弹开？
    - **断电保护**：停电时是否有应急照明和自动平层功能？
    - 超载报警是否正常？
- **可维护性**
    - 故障代码是否易于读取和诊断？
    - 零部件（如灯泡、按钮）是否易于更换？
- **可移植性**
    - 电梯是否能适应不同建筑结构（井道尺寸、楼层高度）？
    - 是否能适应不同的电压波动或井道环境？

## 4. 饮水机

> **核心关注点**：水温控制、卫生与水电安全

- **功能适合性**
    - 能否正常提供热水、温水、冷水？
    - 出水水流是否稳定？
- **性能效率**
    - **加热/制冷速度**：烧开一壶水需要多久？
    - **保温效果**：断电后水温下降的速度。
- **兼容性**
    - 是否适配不同规格的桶装水（5加仑等）或过滤系统？
    - 杯子高度限制（能否接大水壶）？
- **易用性**
    - 换水是否费力（上置式 vs 下置式）？
    - 操作面板是否直观（老人小孩能否看懂）？
    - 是否有童锁功能防止误触烫伤？
    - 是否带有水质指示灯或滤芯更换提示？
- **可靠性**
    - 连续出水（如接满 10 瓶水）电机是否过热保护？
    - 长期使用是否漏水？
    - 平均无故障时间 (MTBF) 是多少？
- **安全性**
    - **防干烧**：没水时是否自动断电？
    - **漏电保护**：外壳是否带电？
- **可维护性**
    - 是否方便清洗内胆/水槽？
    - 滤芯更换是否提示且操作简单？
    - 排水口设计是否合理（方便排空余水）？
- **可移植性**
    - 机器重量与体积是否适合家庭/办公室摆放？
    - 移动时水箱是否容易晃动溢出？

## 5. 杯子

> **核心关注点**：耐用性、复用性、材质安全

- **功能适合性**
    - **盛装功能**：能否正常装水、酒、咖啡等不同液体？
    - **密封性**（若带盖）：倒置或摇晃时是否漏水？
    - **保温/保冷**（若是保温杯）：能否在规定时间内保持温度？
- **性能效率**
    - **耐热/耐冷冲击**：倒入开水是否炸裂？放入冰箱冷冻是否破裂？
    - **容量精度**：刻度线（如有）是否准确？
- **兼容性**
    - **适配性**：能否放入微波炉加热？能否放入洗碗机清洗？
    - **尺寸**：是否能放入标准杯架？
- **易用性**
    - **握持感**：把手设计是否符合人体工学？杯身是否防滑？
    - **饮用体验**：杯口厚度是否适中，喝水是否顺畅不呛口？
    - **清洁度**：内壁是否光滑，是否容易清洗残留污渍？
- **可靠性**
    - **抗摔性**：从桌面高度跌落是否容易破碎？
    - **寿命**：长期使用后，涂层是否脱落？玻璃是否变浑浊？
- **安全性**
    - **材质安全**：是否含铅、镉等重金属（尤其是陶瓷釉面）？
    - **物理安全**：杯口是否有缺口、毛刺，防止割伤嘴唇？
    - **防烫**：装热水时，杯身或把手是否过热导致无法手持？
- **可维护性**
    - **易洁性**：茶垢、咖啡渍是否容易洗掉？
    - **配件更换**：杯盖密封圈老化后是否容易更换？
- **可移植性**
    - **便携性**：重量是否适中？是否有防漏设计方便携带出门？
